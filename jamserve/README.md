# JamServe development

See the [root README](../README.md) for requirements, installation and server configuration. Run the following commands from `jamserve/` after installing dependencies.

| Command | Purpose |
| --- | --- |
| `npm run develop` | Build and restart the server on source changes |
| `npm run build` | Compile into `dist/` |
| `npm run build:prod` | Clean and compile into `dist/` |
| `npm run clean` | Remove `dist/` |
| `npm test` | Run Jest tests |
| `npm run test:watch` | Run tests in watch mode |
| `npm run coverage` | Generate a test coverage report |
| `npm run lint` | Run ESLint |
